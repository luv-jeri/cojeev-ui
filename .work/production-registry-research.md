# Production registry research and bounded release proposal

Research date: 8 September 2026 IST. Read-only source/API assessment; no production changes or browser tests. Local source snapshot: `9ff6c6c`; main was `1768a5f` when checked, with no differences in UI source or example files. Main's generated registry contains 70 UI entries (66 base + Adjuster, Icon, Shape, Preview), and the manifest has 70 examples. The untouched worktree's generated registry was stale, so counts use main's generated output and the 70 source files, not that stale artifact. Recommendations below are product judgments, not third-party endorsements or fidelity acceptance.

**Recommendation:** ship the existing breadth with much better discovery, credible action examples, and at most one new general-purpose entry: CodeBlock with a copy-control part. Do not add another effects library. SahaJiv's warm surfaces, restrained typography, understandable actions, and shared nine-character motion system already form a coherent distinction.

**Nine-preset playground UX**

The implemented names are Glide, Stretch, Jelly, Comet, Ink drop, Rubber, Pebble, Ripple, Halo; Off is a separate tenth choice (`motion/settings.ts:25`). Avoid calling them nine new animations to implement. Root is already implementing the compact surface; the following are details for that work:

- Use plain “Selection motion” and “Body response” labels. Show one selected preset and an adjacent real Tabs group immediately; users should understand that selecting another tab reveals the effect. Add an explicit replay action that changes actual selection, not a fake visual overlay.
- A small Button/IconButton beside the Tabs can demonstrate pointer approach, focus, and press; explain that body settings and selection character are different controls. Keep advanced tier/texture numbers collapsed.
- Show the active preset name, speed, intensity, and “Reset to Glide.” A compact labelled Select is sufficient on mobile; a nine-card autoplay wall would add noise and work without helping selection.
- State that global changes apply across this site and are remembered. `setFlowSettings` and motion setters write localStorage (`settings.ts:123–126`); the Adjuster component's own open/tier state is separate. Do not describe all settings as unpersisted.
- Show effective Off/reduced-motion status visibly. Respect OS reduced motion even when a user selects Jelly; describe the current result without promising movement. Existing `flow.ts:18,35` supplies the quiet-mode precedence.
- Copy the right artifact: `exportMorphJSON()` exports body `cfg`/`TIER`, not flow preset/speed/intensity (`settings.ts:131`). Label it “Body profile,” and provide a separate flow/settings snippet if the user expects a reproducible selection preset. An ancestor `data-flow="jelly"` already pins a local character (`flow.ts:34–37`); global Off still wins.
- Keep one preview mounted per variant/size selection, as root plans. Link advanced settings from each example; preserve a copyable code view matching the shown component and settings. This gives lightweight discovery without duplicating the whole docs tree or adding another motion dependency.

**Public release/distribution findings**

The [directory](https://ui.shadcn.com/docs/directory) makes listed namespaces usable directly in the CLI. The [submission requirements](https://ui.shadcn.com/docs/registry/registry-index) call for public open source, valid registry JSON, a flat registry, and no inline `content` in index-file `files` entries; submission is a PR after directory validation. Main currently has flat `public/r/registry.json` plus sibling item JSON, 71 total items including the base, and zero `content` fields in index file records. This research did not run a fresh public deployment/install. `@sahajiv` was absent from the live directory snapshot, so direct public URLs remain the honest discovery path until registration/configuration exists; don't imply directory inclusion from local namespace configuration alone.

MIT is already present in root `LICENCE` (copyright Sanjay Kumar, 2026), and the builder includes both bundled font OFL files. My initial LICENSE-spelling-only check was incomplete and is corrected here: there is no missing-MIT-file finding. Preserve the source-baseline receipts as provenance while separately tracking now-authorized product refinements.

Keep example logic inside the extracted example functions so `components/example-source.ts` continues to produce complete copyable code without modification.
