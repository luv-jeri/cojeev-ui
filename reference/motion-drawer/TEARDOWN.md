Scope is the component, not the surrounding UI Layouts website. Operate/read mode; the source's simple navigation silhouette leads, with Cojeev typography and semantic colors. No GPU surface, image assets or shaders: browser inspection found only DOM/SVG. Adapt the existing React project; do not scaffold a new site or change its visual identity.

CONFIRMED source: horizontal displacement equals drawer width, spring stiffness 120/damping 25, drag elasticity .1, no momentum, close after .3 width travel toward the correct edge. Merge toggle moves width-68px toward its open position while fading; push travels width+20px; stay only fades. Overlay enters/exits in .3 seconds. Close button stays top-right. Original source lacks focus management; adaptation must retain Radix's dialog accessibility instead of copying that omission.

Adaptation boundaries: default geometry and interaction model are retained; system fonts/colors, accessible labels, safe disabled/controlled behavior, reduced motion and a slightly more responsive spring (180/26) are deliberate changes. Floating, stack and bottom are additional variants, not claimed source clones. Four live examples use different content hierarchy, not color swaps. No product-wide DESIGN.md changes.

Implementation and QA: upstream files use .tsx.txt extensions so the preserved reference is evidence, not compiled app code. The inline launcher measures its route to the close control rather than using the reference's fixed-position offset. Toggle measurement covers controlled/default-open state; presence re-entry restarts the drawer after a rapid close/reopen.
