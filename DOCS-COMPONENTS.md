# Documentation component additions

The owner approved using SahaJiv components for all visible documentation UI while keeping Fumadocs as the documentation framework. Missing helpers may be created from the supplied design system and published as library components.

These additions are tracked separately from the original 66 base components. Reuse an existing base component before adding a helper. A helper must have a real reusable API and be installable through the registry before it is marked complete.

| Addition | Why existing components are insufficient | Registry item | Status |
| --- | --- | --- | --- |
| None yet | Existing components will be assessed first | — | — |

The Copy command control now uses SahaJiv Button, and component previews use SahaJiv Card. The preview still contains Fumadocs default navigation and a native theme selector. Their migration to SahaJiv components is pending the relevant base ports.
