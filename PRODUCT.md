# SahaJiv UI

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users and purpose

Sanjay and developers building SahaJiv use this open-source component registry to build a product centered on monitoring agent activity and taking focused actions. The documentation must make it easy to discover a component, exercise its variants, understand its accessible behavior, and install its source.

## Confirmed constraints

- MIT licence. GitHub Pages hosts documentation and the registry; a custom domain will follow later.
- React, TypeScript, Radix accessibility primitives, Tailwind v4 and Fumadocs. Documentation controls use the SahaJiv library.
- The September 8 overhaul brief explicitly moves beyond static handoff parity toward expressive, carefully composed UI and standardizes choreography on Framer Motion (Motion for React).
- Keep installable source and examples synchronized. Track new components explicitly.
- Demos are local simulations, not evidence of a connected AI backend.

## Evidence

The incumbent release is recorded in RELEASE-REPORT.md. The original kit is in reference/sahajiv-handoff-v4. Intelly reference boards remain in the September 5 design-handoff folder. The active overhaul objective is recorded in OVERHAUL-PLAN.md; prior release gates do not establish completion of that objective.

## Principles

Prioritize visual craft, legible hierarchy, meaningful action, honest state feedback, responsive boundaries, keyboard access, and reduced-motion support. Preserve the product's identity while improving its implementation.
