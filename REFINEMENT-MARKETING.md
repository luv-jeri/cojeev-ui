# Narrative pages and documentation integration

The new home route presents SahaJiv UI through working library components. The header combines library link, icon and theme primitives; the documentation navigation remains the library Sidebar. A real ShapeScene anchors the hero. Native scrolling and explicit keyboard-accessible steps bring Avatar, Badge, Input and Button into an AgentChat composition. The composer appends only local messages. The shape playground changes contour, colour, fill and rotation, and the agent state specimen exposes actual states. Parallax decoration and reveals use the shared quiet-motion decision. Reduced motion presents the finished composition.

The creator route uses the confirmed creator name, describes this project's work and links to the approved GitHub profile. No client claims, metrics, testimonials or contact endpoints were invented. The new page compositions are application layouts made from registry components; they are not new installable primitives. ItemAdornment is the new public primitive from the menu stream.

## Evidence

- First Chromium pass: 390, 768 and 1440 pixels, light and dark; all six contexts passed hero interaction, assembled local composer, shape/tone/fill and keyboard rotation, state controls, responsive navigation, creator contact and reduced-motion static composition.
- WebKit confirmation: 360 and 768 pixels, light and dark; all four contexts passed the same meaningful interactions. These are browser simulations, not a physical iPhone result.
- Opening compositions and full-page screenshots were inspected. Corrections included explicit shape paint in dark mode, near-mobile heading fit and the theme label's paired foreground (owned by the theme stream).
- Documentation integration checks were updated for the new actual Select controls and revised example labels. Initial failures included outdated native-select assertions and a pointer action aimed at a visually hidden radio input; the visible questionnaire label remains the pointer target.
- Independent review found three defects: quiet mode ignored manual assembly steps, keyboard opening left mobile navigation out of the next focus position, and the mobile panel lacked a retained entrance/exit. Those defects were corrected. A 360px light/dark confirmation passed keyboard opening, first-link focus, Escape focus return, and manual assembly steps with reduced motion.
- Documentation integration passed for Calendar and DatePicker, followed by a corrected seven-entry run for Checkbox, Dropzone, Field, Icon, ItemAdornment, Questionnaire and RadioGroup. Checks exercise the actual Select-backed variant/size controls, copied source and meaningful component behavior.
- Final built-source checks and publication are recorded in `REFINEMENT-REPORT.md`. Development captures alone do not imply deployment is complete.
