## The first week, after launch acceptance

1. **Prepare:** record one short, silent demo and one reduced-motion version. Include a working direct install command, licence and honest limitations. Finish the README and confirm the public contact link.
2. **Share on LinkedIn:** one maker post, one demo, one link. Answer genuine questions. A useful follow-up can explain the slider's trade-off: Radix behaviour, original drawn geometry.
3. **Reach out selectively:** one individual creator email; no mass-send list. If commenting, contribute something relevant, disclose that you are the maker, and avoid copying the same pitch elsewhere.
4. **One community launch:** evaluate Show HN when the demo can be tried without registration. Reactiflux depends on its current designated channel rules. Lobsters depends on existing account history; it is not an immediate promotional shortcut. The full report links each community's rules.
5. **Learn:** review actual visits, component interactions and copies separately from installation tests. Fix reported friction before increasing outreach. Do not invent installation counts from website clicks.

These are proposed operating limits, not claims that YouTube forbids every link or that a creator owes a response. [YouTube prohibits repetitive/deceptive spam](https://support.google.com/youtube/answer/2801973); [LinkedIn also prohibits spam](https://www.linkedin.com/help/linkedin/answer/a1338787). No automated commenting, paid placement, account posting or registry submission is part of this work.
