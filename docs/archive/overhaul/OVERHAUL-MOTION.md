# Motion and scroll implementation evidence

September 8, 2026. Local working-tree implementation; no commit or publication performed by this stream.

## Implemented

- `motion/choreography.ts` exports `useChoreography()` returning `{ quiet, transition }`, shared `motionTokens`, and interruptible Motion scalar lanes integrated with the existing deterministic clock. Global Off, Flow Off, reduced motion, and speed settings are respected.
- The shared selection pipeline now uses Motion to interpolate pill, hover, and comet-trail positions and dimensions. Existing stretch/drop/rubber phases remain bounded timers; their actual geometry is animated by Motion. Landing feedback uses Motion springs, including bounded ripple/halo paint. CSS retains colors and geometry layout without also owning the movement.
- The shared appearance hook now uses a single Motion progress owner through open/close reversal. A nonvisual CSS animation retains Radix presence until the Motion exit finishes; native focus and dismissal contracts remain intact. React controlled Toast uses the same owner.
- `TextReveal` now uses Motion `animate`/`stagger`; its former direct `Element.animate` call is removed. Full accessible text remains present and cancellation restores readable words.
- `ScrollArea`/`ScrollBar` retain Radix native scrolling/dragging while a fixed-topology SVG thumb widens and bends using shared Motion springs. The viewport is keyboard-focusable, and the additive `viewportProps` API exposes native viewport refs/listeners/labels. Delayed Radix mounts attach their visibility observer correctly. Offscreen/hidden/reduced/Off states stop decorative motion.
- `PageScrollBar` is exported from the same registry item and mounted by the parent in the app layout. It renders a fixed document rail with the same contour/springs, while `document.scrollingElement` remains the actual scroll owner. Track clicks, pointer-captured dragging, ARIA scrollbar semantics, Home/End/arrows/PageUp/PageDown, native page keys, hash links, and touch retain meaningful behavior. A reference-counted mount cleanup restores the prior native scrollbar attribute; pointer dragging does not steal focus. Mount once inside the body as `<PageScrollBar />`; optional props are standard div attributes/ref/handlers.
- The existing bespoke SVG body/rim solver remains the contour owner for morph surfaces. This is a shared transition-engine migration, not a claim that every authored component CSS animation or contour physics loop has been replaced.

## ShapeMorph: new reusable library component

- `ShapeMorph` is an authored library component exported from `ui/shape.tsx`; it accepts typed `SignatureShapeName`, `variant="fill" | "outline"`, normal SVG props/ref, and an optional accessible `label`. Without a label it is decorative. It interpolates the visible SVG path through Motion when `name` changes, preserving the current path during interruption. Off, reduced motion, hidden tab, and offscreen cases settle directly rather than running a background loop.
- The parent authored 12 original fixed-topology silhouettes in `lib/signature-shapes.ts`. Each has 96 cubic segments in a normalized 100×100 box. No supplied raster moodboard images are bundled. The existing static `Shape` API remains available, with all 36 shapes exposed in its gallery.
- `ShapeExample` now provides 12 native button choices, four palette choices, a fill/outline toggle, and the 36-shape catalog. The shared root `--c` initially leaked a cream paint into the new demo; the preview now uses ordinary inherited color and each static demo Shape explicitly scopes its paint to the selected palette.
- Unit evidence checks all 12 paths and 720 pairwise/progress interpolation samples for stable topology and finite, bounded coordinates. SSR checks label/decorative semantics and outline paint. Browser evidence at 1440px/390px proves a real intermediate path, pointer change to cloud-3, keyboard Enter to pebble-tall, exact Mulberry-to-Olive preview/gallery color change, fill/outline behavior, static Off/reduced motion, 36 gallery entries, 12 choices, equal client/scroll widths, and no runtime errors. Evidence: `output/playwright/overhaul-motion/shape-results.json`, `shapes-1440.png`, and `shapes-390.png`.

## Public lifecycle and presence architecture

- New `ui/presence.tsx` exports `MotionPresence`, `MotionSurface`, `presencePresets`, `PresencePreset`, and both prop types. `MotionSurface` has explicit initial/animate/exit states for fade, rise, slide, scale, and mask; additive overrides and a seconds-based `delay` allow composition with the shared springs/easing/stagger policy. It uses `useChoreography()` for global Off, Flow Off, and reduced motion.
- `MotionSurface asChild` merges onto one ref-capable semantic child using Radix Slot and Motion. Native element, ref, handlers, supplied `data-slot`, attributes, and child markup remain intact. Lifecycle translation/scale uses individual CSS properties, leaving the bespoke contour's `transform` channel available. The test proves a native disabled button remains a single button with no extra wrapper.
- Place a persistent external `MotionPresence` around the actual keyed conditional children. Default `initial={false}` keeps initial SSR content readable; new keyed children still enter. An internal boundary cannot retain its own parent removal. The shared surface becomes inert, aria-hidden, and non-interactive while retained for exit, including when `asChild` has explicit accessibility props. Quiet mode uses a zero-duration exit.
- The parent and agent stream adopted the API at actual conditional boundaries in `components/component-preview.tsx`, `components/examples/motion-primitives.tsx`, `components/examples/agent.tsx`, and `registry/cojeev/ui/agent-chat.tsx`: keyed docs sample replacement; the public presence demo; agent messages/welcome/completion; attachments; errors; permission decisions; options. Agent evidence shows pending Deny/Allow controls retained at 30ms with inert=true and aria-hidden=true, removed by 350ms; reduced motion has no retained node at 30ms. Evidence: `output/playwright/overhaul-agent-presence/lifecycle.json`.
- The public presence demo passed at 1440px and 390px with real intermediate opacity on the retained Card, native `data-slot="card"`, inert/aria-hidden exit state, final removal, rapid reversal, and immediate Off/reduced exits. The browser collected frame samples through the exit so a single endpoint snapshot could not masquerade as interpolation. No runtime errors. Evidence: `output/playwright/overhaul-motion/public-presence-results.json` and `public-presence-*.png`.
- Radix portals retain their existing native presence/focus mechanisms through the bounded CSS sentinel adapter described above. They are not blindly wrapped in a second AnimatePresence. Arbitrary consumer conditionals still need their own external boundary. Universal per-component internal state adoption has not been claimed by this stream; the authored contour solver and remaining component CSS animation owners are explicitly not a complete Motion-engine rewrite.
