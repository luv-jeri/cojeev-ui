# Archive — historical plans and evidence

Every document in this folder is a historical record: a plan, an audit or a
report as it stood when it was written. None of it is a current completion
claim. A plan here states what was intended, which is not evidence that it was
delivered; a report here states what was observed then, which is not evidence
that it holds now. Counts, verdicts, entry totals and "current" statements
inside them are historical. Several say so in their own opening paragraph.

Nothing here is maintained or corrected. Files were moved out of the repository
root with their content intact; only relative links were repaired so they still
resolve from the new location.
